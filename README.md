# Adrasan Engin Kaptan Site

Bu paket GitHub Pages veya Netlify üzerinde yayınlanabilir statik web sitesi dosyalarını içerir.

## Dosyalar
- index.html
- suluada-turu.html
- ozel-tur.html
- eylul-apart.html
- galeri.html
- iletisim.html
- styles.css
- script.js
- assets/

## Yayın
1. Dosyaları GitHub reposuna yükleyin.
2. Settings > Pages bölümünden branch seçin.
3. sitemap.xml içindeki example.com alanını kendi domaininiz ile değiştirin.
